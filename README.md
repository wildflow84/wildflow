# MagicCalc (마술용 계산기)

겉보기엔 평범한 계산기. 아래 순서로 누르면 마술 모드가 켜진다.

1. `A × B × C +` (각 1~3자리)
2. 관객이 아무 숫자나 마구 누른다 → 화면엔 숫자가 올라가지만 실제 숫자는 정해져 있음
3. `=` → 결과가 **현재 연월일시분 + 1분** (`yyMMddHHmm`, 한국 시간)

예) 2026-11-01 17:53 → `2611011754`

- 숨겨진 숫자 X = 목표값 − A×B×C (항상 10자리). 관객이 10자리 넘게 누르면 무시, 덜 눌러도 `=` 시 자동 완성.
- 목표 시각은 **관객이 첫 숫자를 누르는 순간** 기준으로 고정됨. 보정 분은 `CalcEngine.OFFSET_MINUTES`.
- 위 패턴이 아니면 그냥 일반 정수 계산기(사칙연산, 우선순위 적용).
- 빌드: Android Studio로 열기 → Run. (minSdk 26)
- 로직은 `app/src/main/java/com/wildflow/magiccalc/CalcEngine.kt`, 테스트는 `app/src/test/...`
